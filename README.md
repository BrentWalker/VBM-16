# VBM-16 v1.0 by BeatSmith

Video beat machine. Turn any video into a drum kit: every hit plays its own piece of video.

- App: https://brentwalker.github.io/VBM-16/
- Tutorial: https://brentwalker.github.io/VBM-16/tutorial.html

## v1.0 features
- **Video in:** record or import any number of videos. Types: drums, bass, guitar, keys, vox, samples, FX, chaos. AUTO CHOP (fills the next empty bank) or JUST UPLOAD. Scale reader shows each video's key and each chop's note.
- **Slicer:** Loop Lock style waveform, crossable edges, hold to slide, edge pull from the side, loop preview, nudges, beat lengths, video slip up to 1 second.
- **Banks:** 8 banks of 16 pads (128 chops), hold to reorder, hold-to-clear button.
- **Pads:** polyphonic with mute groups, one shot / gate / loop, fades, decay, freeze frame, pitch, level, reverse, KEYS mode with note names.
- **Sequencer:** 4 tracks, 16 patterns up to 8 bars, chain, live record, step nudge, swing, metronome.
- **FX:** LOW, HIGH, 1/2, ECHO, ST8, ST16, REV, OCT↓. Track FX: 2 per track from GAIN, DRV, LCUT, HCUT, LBST, HBST, VERB, DLY with amount sliders.
- **Video:** MIX, FOCUS, latest and 4-track views, resizable window, FIT/FILL, MIX layouts (stack, grid, PIP, collage, diagonal), picture FX (zoom, shake, VHS, duotone), waveform overlay, producer tag, pinch zoom.
- **Save:** sessions (.zip), samples (WAV), autosave, INIT, undo/redo, export with loop count and format.
- **Layout:** every panel minimizes; minimized panels can be dragged into any order.

Single-file web app (index.html). Installs to the phone home screen and works offline after the first visit.
